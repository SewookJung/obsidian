# Second Brain Project

배운 것을 체계적으로 축적하고, 아이디어를 실행으로 옮기기 위한 개인 지식 관리 시스템

---

## 방법론

제텔카스텐으로 지식을 축적하고, PARA로 실행을 관리하며, Obsidian으로 이를 연결하고 운영하는 구조


### 제텔카스텐 (Zettelkasten)

지식을 원자적 노트로 쪼개고 서로 연결하여 축적하는 사고 중심 방법론

- **Inbox**: 일시적 노트 (빠른 포착, 1~2일 내 처리)
- **Literature Notes**: 문헌 노트 (자료를 자기 말로 정리)
- **Permanent Notes**: 영구 노트 (핵심 지식 자산, flat 구조)


### 파라 (PARA Method)

프로젝트와 업무를 관리하여 아이디어를 실행으로 전환하는 실행 중심 방법론

- **Projects**: 마감 있는 진행 중 프로젝트
- **Areas**: 지속 관리 영역 (업무, 회의 등)
- **Resources**: 원본 자료를 설명하는 마크다운 노트 (링크, 출처, 메모 등)
- **Archive**: 완료/비활성 항목

### 보조

- **MOC**: Map of Content (주제별 영구 노트 목차)
- **Templates**: 노트 템플릿
- **Attachments**: 물리적 파일 보관 (PDF, 이미지, 엑셀 등 마크다운이 아닌 모든 파일)

---

## 폴더 구조

제텔카스텐 -> PARA -> 보조 순으로 디렉토리 순서를 고정

```
┌─ Zettelkasten ───────────────┐
│  01. Inbox/                  │
│  02. Literature Notes/       │
│  03. Permanent Notes/        │
├─ PARA ───────────────────────┤
│  04. Projects/               │
│  05. Areas/                  │
│  06. Resources/              │
│  07. Archive/                │
├─ Support ────────────────────┤
│  08. MOC/                    │
│  09. Templates/              │
│  10. Attachments/            │
└──────────────────────────────┘
```

## 사용법

### 포착하기 — 모든 정보의 단일 진입점

모든 것은 `01. Inbox/`에 먼저 넣는다. 분류하느라 흐름을 끊지 말고 빠르게 포착하는 데 집중.

- 내 생각/아이디어: 한 줄 메모도 괜찮음
- 외부 자료: 링크, 스크랩, PDF도 일단 여기에
- 공부할 주제: "이거 나중에 공부해야지"도 여기에

### 분류 및 가공하기 — Inbox 비우기

Inbox에 쌓인 항목을 열어보고 목적에 맞게 분배한다. (목표: Inbox Zero)

- **보관할 원본 자료인가?** → `06. Resources/`로 이동
- **읽고 내 언어로 소화할 건가?** → `02. Literature Notes/`에 자기 말로 정리 (복붙 금지, 출처 필수)
- **나만의 독립적 아이디어인가?** → `03. Permanent Notes/`로 가공 (원자성, `[[링크]]` 필수)
- **마감 있는 실행 목표인가?** → `04. Projects/`로 이동
- **가치 없는가?** → 삭제

### 구조화하기

영구 노트가 한 주제로 5개 이상 모이면 `08. MOC/`에 목차 노트를 만들어 주제별 지도를 구성한다.

### 정리 주기

- **매일**: Inbox 확인 → 분류하거나 삭제 (Inbox가 쌓이면 시스템 붕괴)
- **매주**: 문헌 노트 점검, 영구 노트 간 연결 보강, MOC 업데이트
