# Second Brain

배운 것을 체계적으로 축적하고 연결하기 위한 개인 지식 관리 시스템

---

## 방법론

제텔카스텐(Zettelkasten)으로 지식을 축적하고, Obsidian으로 연결하고 운영하는 구조

### 제텔카스텐 (Zettelkasten)

지식을 원자적 노트로 쪼개고 서로 연결하여 축적하는 사고 중심 방법론

- **Inbox**: 일시적 노트. 빠른 포착용, 주 2~3회 비우기
- **Literature Notes**: 자료를 읽고 자기 말로 정리한 노트. 복붙 금지, 출처 필수
- **Permanent Notes**: 핵심 지식 자산. 하나의 노트에 하나의 아이디어, flat 구조

## 폴더 구조

```
00. MOC/              ← 주제별 Permanent Notes 목차
01. Inbox/            ← 빠른 포착용 임시 노트
02. Literature Notes/ ← 자료를 읽고 자기 말로 정리한 노트
03. Permanent Notes/  ← 정제된 영구 노트
09. Templates/        ← 노트 템플릿
10. Attachments/      ← PDF, 이미지 등 물리적 파일
```

---

## 사용법

### 1. 포착하기 — 모든 정보의 단일 진입점

모든 것은 `01. Inbox/`에 먼저 넣는다. 분류하느라 흐름을 끊지 말고 빠르게 포착하는 데 집중.

- 내 생각/아이디어: 한 줄 메모도 괜찮음
- 외부 자료: 링크, 스크랩, PDF도 일단 여기에
- 공부할 주제: "이거 나중에 공부해야지"도 여기에

### 2. 분류하기 — Inbox 비우기 (주 2~3회)

Inbox에 쌓인 항목을 열어보고 목적에 맞게 분배한다.

- **읽고 내 언어로 소화할 건가?** → `02. Literature Notes/`에 자기 말로 정리
- **나만의 독립적 아이디어인가?** → `03. Permanent Notes/`로 가공
- **물리적 파일인가?** (PDF, 이미지 등) → `10. Attachments/`로 이동
- **가치 없는가?** → 삭제

### 3. 연결하기 — 지식 그래프 만들기

Permanent Note를 작성할 때 반드시 기존 노트와 `[[링크]]`로 연결한다.

연결할 노트가 없다면, 그 아이디어가 정말 Permanent Note가 될 만한지 재고한다.

한 주제로 Permanent Notes가 5개 이상 모이면 `00. MOC/`에 목차 노트를 만든다.


### 정리 주기

- **주 2~3회**: Inbox 확인 → 분류하거나 삭제
- **매주**: Literature Notes 점검, Permanent Notes 간 연결 보강, MOC 업데이트

---

## 연결 규칙

- 주제 분류는 `[[링크]]`와 MOC가 담당
- 기술/고유명사는 영문 공식명, 추상 개념은 영어/한국어 모두 가능
- 영어/한국어 양쪽 표기가 필요한 개념은 `aliases`로 통합
- 단수형, 명사형 사용

## 태그 규칙

태그는 출처 유형 분류에만 사용한다.

| 태그 | 용도 |
|------|------|
| `#source/book` | 도서 |
| `#source/article` | 아티클, 블로그, 뉴스 |
| `#source/video` | 영상, 강의 |
| `#source/docs` | 공식 문서, 레퍼런스 |
