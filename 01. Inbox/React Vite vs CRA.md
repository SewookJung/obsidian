# Vite vs CRA(Create-React-App)

맨 처음 [[CRA]]를 이용해서 [[React]] 서버를 구동했던 기억이 있음
근데 지금은 AI를 이용해 바이브 코딩을 하다보니
초기 설정에 대해서 기억이 잘 나지 않음

확인해보니 현재 [[Frontend]] 프로젝트가 [[Vite]]로 설정이 되어 있음
- Vite 역할이 정확히 뭔지 모르겠음
- Vite와 CRA의 차이도 모르겠음
- 근데 공식 문서에는 framework를 사용하라고 하던데 그것도 한번 알아보자
